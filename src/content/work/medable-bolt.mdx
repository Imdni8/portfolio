<StorySection heading="Problem" divider split="even">

> User had to choose the right agent and keep all MCPs authenticated before they could start a conversation, leading to high setup friction

The reason for having multiple agents was that each one could be audited and approved for
specific tasks, which is great for compliance. But it also forced user to find the right agent
before delegating their task. Bolt was conceived for solving this problem.
